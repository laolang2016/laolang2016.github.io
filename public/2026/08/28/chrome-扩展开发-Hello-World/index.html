初次使用可能需要多启动几次

  1. pnpm dev
  2. vscode 中 F5 即可打开一个全新的 chrome 实例
  3. 手动加载扩展
  4. 在启动的 chrome 实例上新开一个页面, 进入 launch.json 指定的页面
  5. 控制台日志筛选为插件日志
  6. 源代码来源中,将 content.ts.js 从忽略列表中移除
  7. popup 页面右键查看,可看已加载来源映射的 ts 文件
