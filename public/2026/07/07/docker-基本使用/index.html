常用命令

镜像

命令 作用 说明
docker images 查看本地所有镜像
docker image ls 同 docker images，列出镜像
docker pull <镜像名>:<标签> 从仓库下载镜像（如 docker pull nginx:latest）
docker build -t <名称:标签> . 用当前目录的 Dockerfile 构建镜像
docker rmi <镜像ID或名称> 删除一个镜像
docker rmi $(docker images -q) 删除所有未使用的镜像（慎用！）
docker image prune 清理悬空镜像（build 失败残留）

容器

命令 作用 说明
docker run [选项] <镜像名> 创建并启动一个容器
docker start <容器ID或名称> 启动已停止的容器
docker stop <容器ID或名称> 停止正在运行的容器（优雅关闭）
docker restart <容器ID或名称> 重启容器
docker rm <容器ID或名称> 删除已停止的容器
docker rm -f <容器ID> 强制删除正在运行的容器
docker ps 查看正在运行的容器
docker logs <容器ID> 查看容器输出日志
docker exec -it <容器ID> /bin/bash 进入容器内部执行命令（常用）
docker rename <旧名> <新名> 重命名容器

数据卷

命令 作用 说明
docker volume create <卷名> 创建一个数据卷
docker volume ls 查看所有数据卷
docker volume rm <卷名> 删除数据卷
docker volume prune 删除所有未使用的卷

网络

命令 作用 说明
docker network ls 查看所有网络
docker network create <网络名> 创建自定义网络
docker network connect <网络> <容器> 将容器加入网络
docker network disconnect <网络> <容器> 将容器移出网络
docker network rm <网络名> 删除网络

docker compose

命令 作用 说明
docker-compose up 启动所有服务（前台运行）
docker-compose up -d 后台启动所有服务
docker-compose down 停止并删除所有服务
docker-compose ps 查看服务状态
docker-compose logs 查看所有服务日志
docker-compose build 重新构建服务镜像

清理与维护

命令 作用 说明
docker system df 查看 Docker 磁盘使用情况
docker system prune 清理所有未使用的资源（容器、网络、镜像、构建缓存）
docker system prune -a 清理所有未使用的镜像（包括未被引用的）
docker builder prune 清理构建缓存
