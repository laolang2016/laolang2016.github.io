## 创建虚拟环境

```bash
# 创建项目目录
$ mkdir httprun

$ source .venv/Scripts/activate
```

### 配置 uv 源

**推荐使用项目级的 `pyproject.toml`**

**配置**

> 注意: 由于 `toml` 语法规则的限制, `tool.uv` 必须在 `[[tool.uv.index]]` 之前

```toml
# python 解释器源
[tool.uv]
python-install-mirror = "https://mirrors.ustc.edu.cn/python-build-standalone"

# pypi 镜像源
[[tool.uv.index]]
url = "https://pypi.tuna.tsinghua.edu.cn/simple"
default = true
```

**使用**

修改 `.python-version`

```
3.13
```
