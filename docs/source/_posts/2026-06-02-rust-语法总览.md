# 变量与不可变性

## 变量可变性

```rust
fn main() {
    // 声明变量使用 let
    // let 声明的变量默认不可变
    let x = 1;
    println!("x = {x}");
    // x = 2; // 报错 Cannot assign a new a value to an immutable variable more than once

    // 使用 let mut 声明的变量是可变的
    let mut y = 1;
    println!("y = {y}");
    y = 2;
    println!("y = {y}");
}
```

fn main() {

## 静态变量


### 基本用法

```rust
// 全局可见, 但不可修改
static AGE: i32 = 18;

// 必须在 unsafe 代码中, 且可修改
static mut AGE_MUT: i32 = 20;

fn main() {
    println!("AGE is {}", AGE);
    unsafe {
        // static mut 变量必须在 unsafe 代码中使用
        println!("AGE_MUT = {}",std::ptr::addr_of!(AGE_MUT).read());

        // static mut 可以修改值
        AGE_MUT = AGE_MUT + 1;
        println!("AGE_MUT = {}",std::ptr::addr_of!(AGE_MUT).read());
    }
}
```

### 原子类型

使用原子类型可避免 `std::ptr::addr_of!(AGE_MUT).read())` 这种复杂操作

原生原子类型支持基础整数,布尔值,指针/引用, 浮点数推荐使用 `atomic-float`, 自定义结构体推荐使用 `portable-atomic`

```rust
use std::sync::atomic::{AtomicI32, Ordering};

static AGE_MUT: AtomicI32 = AtomicI32::new(18);

fn main() {
    println!("AGE_MUT = {}",AGE_MUT.load(Ordering::Relaxed));
    AGE_MUT.store(20, Ordering::Relaxed);
    println!("AGE_MUT = {}",AGE_MUT.load(Ordering::Relaxed));
}
```

# 控制流

```rust
fn main() {
    // 1. if / else if / else (分支控制，本身也是表达式)
    let number = 6;
    if number % 4 == 0 {
        println!("number 可被 4 整除");
    } else if number % 3 == 0 {
        println!("number 可被 3 整除");
    } else {
        println!("无法整除");
    }

    // if 作为表达式返回值
    let condition = true;
    let val = if condition { 5 } else { 6 };
    println!("if 表达式返回值: {val}");

    // 2. loop (无限循环，支持返回值与循环标签)
    let mut counter = 0;
    let result = 'outer: loop {
        counter += 1;
        if counter == 10 {
            break 'outer counter * 2; // 使用标签退出并带回返回值
        }
    };
    println!("loop 循环返回值: {result}");

    // 3. while (条件循环)
    let mut number = 3;
    while number != 0 {
        println!("while 倒计时: {number}");
        number -= 1;
    }

    // 4. for (区间与迭代器循环)
    // 遍历区间 (包含 1 不包含 4)
    for i in 1..4 {
        println!("for 区间: {i}");
    }
    // 遍历数组切片
    let arr = [10, 20, 30];
    for item in &arr {
        println!("for 数组元素: {item}");
    }

    // 5. match (模式匹配，需穷尽所有可能)
    let number = 13;
    match number {
        1 => println!("数字是 1"),
        2 | 3 | 5 | 7 | 11 => println!("这是一个小质数"),
        13..=19 => println!("十几的数字"), // 闭区间匹配
        _ => println!("其他数字"),          // 通配符处理剩余可能
    }

    // 6. if let (只关心单一模式匹配的简写)
    let config_max: Option<i32> = Some(100);
    if let Some(max) = config_max {
        println!("if let 匹配成功，最大值设置为: {max}");
    }

    // 7. while let (根据模式匹配持续循环)
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        println!("while let 弹出的元素: {top}");
    }
}
```

# 所有权 , 引用与借用 , slice

Rust 的核心内存安全机制建立在**所有权（Ownership）**、**借用（Borrowing）**与 **切片（Slice）** 之上。以下是现代 Rust 中最常用且标准的语法规范。

---

## 所有权（Ownership）核心规则

Rust 中每个值都有一个所有者（变量），同一时间只能有一个所有者。当所有者离开作用域时，值会被自动释放（Drop）。

### 语义分化：Move 与 Copy
* **Move 语义（堆内存/复杂类型）**：赋值或传参时**转移所有权**，原变量失效。
* **Copy 语义（栈内存/基础类型）**：实现了 `Copy` Trait 的类型（如 `i32`, `bool`, `char` 等），赋值时**自动深拷贝**，原变量依然有效。

```rust
fn main() {
    // 1. Move 语义
    let s1 = String::from("hello");
    let s2 = s1; // 所有权转移给 s2，s1 从此失效
    // println!("{s1}"); // 编译报错！s1 已被 move

    // 2. Copy 语义
    let x = 42;
    let y = x; // 自动按字节复制
    println!("x: {x}, y: {y}"); // 合法！x 和 y 均有效

    // 3. 函数调用与所有权
    let s3 = String::from("world");
    take_ownership(s3); // s3 的所有权传入函数
    // println!("{s3}"); // 编译报错！
}

fn take_ownership(some_string: String) {
    println!("{some_string}");
} // some_string 在此处离开作用域，内存被自动释放
```

---

## 引用与借用（References & Borrowing）

### 引用与借用的关系

通过“借用”（创建指针），可以在不获取所有权的情况下使用数据。

引用（Reference）：是一种数据类型或语言机制。它是指向某块内存地址的指针，并携带着编译器施加的类型安全与生命周期信息（如 &T 和 &mut T）。

借用（Borrowing）：是一种行为或语义过程。指在不获取数据所有权（Ownership）的前提下，临时使用该数据。创建引用的这个“动作”本身，在语义上就叫做“借用”。

比喻：

你有一本书（所有权）。

你的朋友想看，你把书借给他（借用的行为）。

朋友手里拿到的那张“借书凭证”或访问权（引用的实体）。

即: 借用是逻辑概念,引用是实现方式

### 借用规则（二选一原则）
在任意给定作用域内，只允许满足以下**两个条件之一**：
1. **任意多个不可变引用 (`&T`)**
2. **有且仅有一个可变引用 (`&mut T`)**

```rust
fn main() {
    let mut s = String::from("hello");

    // 不可变借用（只读，可共存多个）
    let r1 = &s;
    let r2 = &s;
    println!("{r1} 和 {r2}"); // 读操作完全安全

    // NLL (Non-Lexical Lifetimes) 特性：
    // r1, r2 在此之后不再使用，其生命周期在此结束！

    // 可变借用（可读写，排他性）
    let r3 = &mut s;
    r3.push_str(", world");
    println!("{r3}");
}
```

### 结合解构与函数形参
```rust
struct Point { x: i32, y: i32 }

fn calculate_length(s: &String) -> usize { // 接收不可变借用
    s.len()
}

fn append_marker(s: &mut String) { // 接收可变借用
    s.push_str(" [done]");
}

fn main() {
    let mut p = Point { x: 10, y: 20 };
    
    // 在 pattern matching 中借用字段
    let Point { ref x, ref mut y } = p;
    *y += 5; // 解引用修改
    println!("x: {x}, y: {y}");
}
```

## 切片（Slice）语法

切片是**针对集合中连续元素序列的只读或可变视图（无所有权引用）**。在内存中由“指针 + 长度”双字构成。

### 字符串切片 (`&str`)
```rust
fn main() {
    let s = String::from("hello world");

    // 范围切片语法 [start..end]（前闭后开）
    let hello: &str = &s[0..5];
    let world: &str = &s[6..11];

    // 语法糖简写
    let slice1 = &s[..5];  // 等价于 [0..5]
    let slice2 = &s[6..];  // 等价于 [6..s.len()]
    let slice3 = &s[..];   // 代表全量切片

    println!("{hello}, {world}");
}
```

### 数组与 Vector 切片 (`&[T]`)
```rust
fn main() {
    let arr = [1, 2, 3, 4, 5];
    let vec = vec![10, 20, 30, 40, 50];

    // 获取固定大小数组/动态数组的切片
    let arr_slice: &[i32] = &arr[1..4]; // [2, 3, 4]
    let vec_slice: &[i32] = &vec[..3];  // [10, 20, 30]

    // 可变切片 (&mut [T])
    let mut numbers = vec![1, 2, 3, 4];
    let mut_slice: &mut [i32] = &mut numbers[..2];
    mut_slice[0] = 99; // 修改底层数组数据
}
```

## 最佳实践与 Idiomatic Rust 惯用语法

### 函数参数的隐式 Deref 转换（使用切片替代具体集合引用）
**反模式**：函数形参写 `&String` 或 `&Vec<T>`。  
**推荐模式**：形参写 `&str` 或 `&[T]`，可同时兼容字面量、堆分配对象以及切片自身。

```rust
// 推荐写法：能同时接收 &String 和 &str
fn print_message(msg: &str) {
    println!("{msg}");
}

// 推荐写法：能同时接收 &Vec<i32>、&[i32; N] 数组以及部分切片
fn sum(numbers: &[i32]) -> i32 {
    numbers.iter().sum()
}

fn main() {
    let s_string = String::from("hello");
    let s_str = "hello";

    print_message(&s_string); // 自动 Deref 转换: &String -> &str
    print_message(s_str);

    let v = vec![1, 2, 3];
    let a = [1, 2, 3];
    println!("{}", sum(&v)); // 自动 Deref 转换: &Vec<i32> -> &[i32]
    println!("{}", sum(&a));
}
```

### 使用 `.clone()` / `.to_owned()` 显式避开生命周期复杂性
当需要独立所有权时，显式深拷贝：
* `&str` $\rightarrow$ `String`：使用 `s.to_string()` 或 `s.to_owned()`
* 实现了 `Clone` 的结构体/集合：使用 `obj.clone()`

## 编码避坑指南

1. **悬垂引用（Dangling Reference）**：Rust 编译器在编译期就会杜绝“返回函数内部局部变量引用”的操作。
   ```rust
   // 错误代码！不能返回函数局部变量的引用
   // fn invalid() -> &String {
   //     let s = String::from("hello");
   //     &s 
   // } // s 在这里已被 drop，返回引用会导致悬垂指针

   // 正确写法：直接转移所有权
   fn valid() -> String {
       String::from("hello")
   }
   ```
2. **迭代器失效防护**：在遍历容器时修改容器会导致编译报错。
   ```rust
   let mut list = vec![1, 2, 3];
   // for item in &list {
   //     list.push(4); // 错误！不可变借用遍历期间不能对 list 进行可变借用
   // }
   ```

# 自定义与结构化类型

## 结构体

```rust
// 1. 具名字段结构体 (Named-field Struct)
#[derive(Debug)] // 自动实现 Debug 特质，方便 println!("{:?}", user) 打印
struct User {
    username: String,
    email: String,
    sign_in_count: u64,
    active: bool,
}

// 为 User 结构体实现方法 (Methods) 和关联函数 (Associated Functions)
impl User {
    // 关联函数（构造函数）：没有 self 参数，用 User::new(...) 调用
    fn new(username: String, email: String) -> Self {
        Self {
            username,
            email,
            sign_in_count: 1,
            active: true,
        }
    }

    // 方法：接收 &self (不可变借用)
    fn display(&self) {
        println!("用户: {}, 邮箱: {}, 状态: {}", self.username, self.email, self.active);
    }

    // 方法：接收 &mut self (可变借用，修改内部状态)
    fn deactivate(&mut self) {
        self.active = false;
    }
}

// 2. 元组结构体 (Tuple Struct) - 带有类型名称，但字段无显式名称
#[derive(Debug)]
struct Color(i32, i32, i32);

// 3. 类单元结构体 (Unit-like Struct) - 不占内存空间，常用于实现特定的 Trait 行为
#[derive(Debug)]
struct AlwaysEqual;

fn main() {
    // --- 具名字段结构体的实例化与使用 ---
    println!("--- 1. 具名字段结构体与 impl 方法 ---");

    // 使用关联函数构造实例
    let mut user1 = User::new(
        String::from("laolang"),
        String::from("laolang@example.com"),
    );

    // 调用方法
    user1.display();
    user1.deactivate();
    println!("调用 deactivate 后 active 为: {}", user1.active);

    // 结构体更新语法 (Struct Update Syntax)
    // 利用 user1 的部分字段创建 user2（注意：username 等非 Copy 类型会被转移所有权）
    let user2 = User {
        username: String::from("ghost"),
        email: String::from("ghost@example.com"),
        ..user1 // 剩余字段从 user1 填充
    };
    println!("user2: {:?}", user2);

    // --- 元组结构体 ---
    println!("\n--- 2. 元组结构体 ---");
    let black = Color(0, 0, 0);
    // 通过 .0, .1, .2 索引访问字段
    println!("R: {}, G: {}, B: {}", black.0, black.1, black.2);

    // --- 结构体模式匹配解构 ---
    println!("\n--- 3. 结构体解构 ---");
    let User { username, active, .. } = user2;
    println!("解构提取 -> 名字: {username}, 激活状态: {active}");

    // --- 类单元结构体 ---
    println!("\n--- 4. 类单元结构体 ---");
    let _unit_instance = AlwaysEqual;
    println!("类单元结构体实例: {:?}", _unit_instance);
}
```

# package , crate 和 module

在现代 Rust（Rust 2018 / 2021 / 2024 Edition）中，代码组织遵循“**约定优于配置**”原则。以下是标准且通用的 Package、Crate 与 Module 语法规范。

---

## Package（包）与依赖管理

Package 是由 `Cargo.toml` 管理的项目文件集合。

### 依赖引入 (`Cargo.toml`)
```toml
[dependencies]
# 1. 社区公有库（来自于 crates.io）
serde = "1.0"
log = "0.4"

# 2. 本地相对路径依赖（用于多模块/Monorepo 组织）
my_utils = { path = "../my_utils" }
```

---

## Crate（单元包）入口约定

Rust 依靠默认文件系统路径自动识别 Crate 树的根节点，无需手动配置：

* **Library Crate（库）**：`src/lib.rs`
* **Binary Crate（可执行程序）**：`src/main.rs`
* **Integration Tests（集成测试）**：`tests/xxx.rs`（`tests/` 下的每一个 `.rs` 文件都会被独立编译为一个测试 Crate）

---

## Module（模块）声明与组织

在父文件（如 `lib.rs` 或 `main.rs`）中使用 `mod` 关键字声明并挂载子模块。

### 基础声明语法
* `mod foo;`：声明私有模块（仅限当前 Crate 内部访问）。
* `pub mod foo;`：声明公有模块（可被外部 Crate 或上层导入访问）。
* `pub(crate) mod foo;`：限制可见性（仅在当前 Crate 内部任意位置可见，对外隐藏）。

### 结构模式 A：单文件模式 (Single File)
适用于功能较简单、无需再往下拆分的文件。

```text
src/
├── lib.rs        --> 内容：pub mod logger;
└── logger.rs     --> 对应 `logger` 模块的代码实现
```

### 结构模式 B：同名文件 + 同名目录模式 (Modern Submodule)
适用于模块变得复杂、需要继续拆分出子模块的场景（**官方推荐标准**）。

```text
src/
├── lib.rs        --> 内容：pub mod logger;
├── logger.rs     --> logger 模块的入口（内容：pub mod writer;）
└── logger/
    └── writer.rs --> 对应 `logger::writer` 子模块
```

---

## 路径导入与重导出 (use & pub use)

### 路径导入
```rust
// 绝对路径：以 `crate` 开头，代表当前 Crate 根模块
use crate::logger::init_logger;

// 相对路径：以 `super` 开头，代表父级模块
use super::config;
```

### 模块重导出 (`pub use`)
用在模块入口文件中，用于**屏蔽内部复杂拆分，向外部暴露干净统一的接口**。

```rust
// src/logger.rs（logger 模块入口文件内部）
mod core;
mod writer;

// 将内部 core 模块中的 Logger 结构体直接暴露给 logger 模块层级
// 外部调用者只需访问 logger::Logger，无需感知内部拆分了 core.rs
pub use core::Logger;
```

---

## 编码禁忌（旧语法黑名单）

1. **不要写 `extern crate xxx;`**：直接在 `Cargo.toml` 中声明依赖即可，Rust 编译器会自动处理引入。
2. **尽量避免使用 `mod.rs`**：除非是在维护古老的 Rust 代码库，新项目优先使用“同名 `.rs` 文件”作为文件夹入口，避免 IDE 中打开一堆同名标签页。
3. **不要使用 `#[path = "..."]` 属性**：让 Rust 依据标准目录路径自动匹配，避免破坏团队统一的文件查找逻辑。



# 泛型、Trait 与生命周期语法总结

Rust 的类型系统依赖 **泛型（Generics）** 实现抽象，**Trait（特质）** 定义行为约束，以及 **生命周期（Lifetimes）** 保证引用引用的有效性。以下是现代 Rust 中最常用且标准的语法与惯用法总结。

---

## 泛型（Generics）

泛型允许在不指定具体类型的情况下编写代码，编译器会在编译期进行**单态化（Monomorphization）**，零运行时开销。

### 结构体、枚举与函数泛型
```rust
// 泛型结构体
struct Point<T, U> {
    x: T,
    y: U,
}

// 泛型枚举（标准库最核心的两个枚举）
enum Option<T> {
    Some(T),
    None,
}

enum Result<T, E> {
    Ok(T),
    Err(E),
}

// 泛型实现块（可针对特定类型进行特化实现）
impl<T, U> Point<T, U> {
    fn mixup<V, W>(self, other: Point<V, W>) -> Point<T, W> {
        Point {
            x: self.x,
            y: other.y,
        }
    }
}
```

## Trait（特质与行为约束）

Trait 定义抽象行为接口。现代 Rust 极度推荐使用 Trait 约束来编写高复用且类型安全的代码。

### 基础定义与实现
```rust
pub trait Summary {
    // 默认实现（可选覆盖）
    fn summarize(&self) -> String {
        String::from("(阅读更多...)")
    }
}

struct Article {
    pub title: String,
    pub content: String,
}

impl Summary for Article {
    fn summarize(&self) -> String {
        format!("《{}》: {}", self.title, self.content)
    }
}
```

### Trait 约束语法糖（Trait Bounds）
```rust
use std::fmt::{Debug, Display};

// 1. impl Trait 语法糖（适用于参数简单场景）
fn notify(item: &impl Summary) {
    println!("{}", item.summarize());
}

// 2. 泛型 Trait Bound + 多重约束 (+)
fn print_debug<T: + Debug Display>(item: &T) {
    println!("{item}: {item:?}");
}

// 3. where 子句（推荐：多约束时保持签名整洁）
fn complex_function<T, U>(t: &T, u: &U) -> i32
where
    T: Display + Clone,
    U: Clone + Debug,
{
    0
}

// 4. 返回实现了某 Trait 的类型（隐藏具体实现类型）
fn returns_summarizable() -> impl Summary {
    Article {
        title: String::from("Rust 探秘"),
        content: String::from("..."),
    }
}
```

## 生命周期（Lifetimes）

生命周期属于 Rust 编译器的静态分析标记（以 `'` 开头），**主要用于辅助编译器验证引用的有效性，避免悬垂指针**。

### 生命周期标注语法
当函数存在多个入参引用且返回引用时，必须标注生命周期关联：

```rust
// 声明生命周期 'a：表示返回的引用的生命周期，不长于入参 x 和 y 共同存活的最短作用域
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}

// 结构体中的引用字段（必须显式标注生命周期）
struct ImportantExcerpt<'a> {
    part: &'a str,
}

impl<'a> ImportantExcerpt<'a> {
    // 方法内部的生命周期省略规则（三条隐式规则自动推导）
    fn announce_and_return_part(&self, announcement: &str) -> &str {
        println!("注意: {announcement}");
        self.part
    }
}
```

### 静态生命周期 `'static`
表示数据在程序的整个运行期间都有效（例如存储在二进制只读区的字符串字面量 `&'static str`）。

## 组合运用：泛型 + Trait 约束 + 生命周期

在实际工程中，三者经常在复杂组件层或通用抽象中联合使用：

```rust
use std::fmt::Display;

// 包含泛型 T、Trait 约束 Display 以及生命周期 'a 的综合示例
fn longest_with_an_announcement<'a, T>(
    x: &'a str,
    y: &'a str,
    ann: T,
) -> &'a str
where
    T: Display,
{
    println!("公告: {ann}");
    if x.len() > y.len() {
        x
    } else {
        y
    }
}
```

## 现代 Rust 惯用语法与最佳实践

### 常用派生宏（Derive Traits）
不需要手动写 `impl`，通过 `#[derive(...)]` 快速让自定义结构体获得标准库的基础能力：

```rust
#[derive(Debug, Clone, PartialEq, Eq, PartialOrd, Ord, Default)]
struct Student {
    name: String,
    age: u8,
}
```

### 生命周期省略规则（Elision Rules）
无需在任何地方都手动写 `'a`。编译器会在以下模式下自动推导：
1. **每一个引用参数**都会获得独立的生命周期参数。
2. 如果**只有一个输入引用参数**，该生命周期会被赋给所有的输出引用。
3. 如果输入参数包含 `&self` 或 `&mut self`，**`self` 的生命周期**会被赋给所有的输出引用。

### Trait 约束的合理选择
* 参数传递轻量对象或视图时，优先使用 `&str` / `&[T]` 而非具体的 `&String` / `&Vec<T>`。
* 需要类型支持基本比较时，使用 `PartialOrd` / `Ord`；需要格式化打印时，使用 `Debug` / `Display`。
