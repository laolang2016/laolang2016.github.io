## 下载地址

https://github.com/apolloconfig/apollo-quick-start/blob/master/sql/apolloportaldb.sql

## portal

直接执行脚本 `apolloportaldb.sql` 即可. 执行之后需要修改如下数据

```sql
update ServerConfig set `Value` = 'dev,stg' where `Key` = 'apollo.portal.envs';
update ServerConfig set `Value` = '{"dev":"http://common-apollo-dev-configservice:8080","stg":"http://common-apollo-stg-configservice:8080"}' where `Key` = 'apollo.portal.meta.servers';
```

其中 `apollo.portal.meta.servers` 的值分别为两个环境的 `configservice` 的地址, 详见下文

## ApolloConfigDBDev

将脚本 `apolloconfigdb.sql` 中的数据库名字修改为 `ApolloConfigDBDev`, 然后执行, 再修改如下数据

```sql
update ServerConfig set `Value` = 'http://192.168.56.105:10123/eureka/' where `Key` = 'eureka.service.url';
```

该地址为宿主机地址

## ApolloConfigDBStg

将脚本 `apolloconfigdb.sql` 中的数据库名字修改为 `ApolloConfigDBStg`, 然后执行, 再修改如下数据

```sql
update ServerConfig set `Value` = 'http://common-apollo-stg-configservice:8080/eureka/' where `Key` = 'eureka.service.url';
```

该地址为 `stg` 环境的 `configservice` 服务名

## ApolloChangeListener

```java
package com.laolang.jx.framework.common.apollo;

import com.ctrip.framework.apollo.model.ConfigChangeEvent;
import com.ctrip.framework.apollo.spring.annotation.ApolloConfigChangeListener;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.BeansException;
import org.springframework.cloud.context.environment.EnvironmentChangeEvent;
import org.springframework.context.ApplicationContext;
import org.springframework.context.ApplicationContextAware;
import org.springframework.stereotype.Component;
import org.springframework.util.StopWatch;

@Slf4j
@Component
public class ApolloChangeListener implements ApplicationContextAware {

    ApplicationContext applicationContext;

    @Override
    public void setApplicationContext(ApplicationContext applicationContext) throws BeansException {
        this.applicationContext = applicationContext;
    }

    /**
     * 注意: 
     * 1. 如果后缀不是 properties , 则需要写出完整的文件名
     * 2. value 是个数组, 可以有多个
     */ 
    @ApolloConfigChangeListener(value = {"application.yml"})
    public void onApolloChange(ConfigChangeEvent changeEvent) {
        StopWatch stopWatch = new StopWatch();
        log.info("apollo chanag start");
        stopWatch.start();
        changeEvent.changedKeys().forEach(key -> {
            log.info("apollo old value: {}={}", key, changeEvent.getChange(key).getOldValue());
            log.info("apollo new value: {}={}", key, changeEvent.getChange(key).getNewValue());
        });
        this.applicationContext.publishEvent(new EnvironmentChangeEvent(changeEvent.changedKeys()));
        stopWatch.stop();
        log.info("apollo chanag end. {} ms", stopWatch.getLastTaskTimeMillis());
    }
}
```
