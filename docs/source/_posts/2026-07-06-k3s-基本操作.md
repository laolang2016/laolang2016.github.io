### 远程登录

设置密码后修改 `/etc/ssh/sshd_config` 文件 和 `/etc/ssh/sshd_config.d/60-cloudimg-settings.conf`

```
PasswordAuthentication yes
```

然后重启 ssh

```
sudo systemctl restart ssh
```

### 启用 universe 仓库

```
sudo add-apt-repository universe
sudo apt update
```

### 设置主机名

```bash
# master 节点
sudo hostnamectl set-hostname k3s-master
# woker1 节点
sudo hostnamectl set-hostname k3s-worker-01
# woker2 节点
sudo hostnamectl set-hostname k3s-worker-02
```

## k3s 安装

### master 节点安装

```bash
curl -sfL https://get.k3s.io | sh -

# 国内使用该命令
curl -sfL https://rancher-mirror.rancher.cn/k3s/k3s-install.sh | INSTALL_K3S_MIRROR=cn sh -
```

使用 `sudo kubectl get nodes` 验证一下

```bash
 sudo kubectl get nodes
NAME           STATUS   ROLES           AGE   VERSION
ubuntu-jammy   Ready    control-plane   12s   v1.36.5+k3s1
```

获取 `token`

```bash
sudo cat /var/lib/rancher/k3s/server/node-token
```


### worker 节点安装

```bash
curl -sfL https://get.k3s.io | K3S_URL=https://myserver:6443 K3S_TOKEN=mynodetoken sh -

# 国内使用该命令
curl -sfL https://rancher-mirror.rancher.cn/k3s/k3s-install.sh | INSTALL_K3S_MIRROR=cn K3S_URL=https://myserver:6443 K3S_TOKEN=mynodetoken sh -
```

具体使用如下

```bash
# master 节点
export MASTER_IP=192.168.56.21
# 来自 master 节点的 /var/lib/rancher/k3s/server/node-token
export TOKEN=K1081a8060187f2b3cf4af89b66483be7a82e6f20b2eb51dd7f13ad00b1879cc540::server:077c6a6bb01e2adc77eb19f33a339a67
# 执行安装
curl -sfL https://rancher-mirror.rancher.cn/k3s/k3s-install.sh | INSTALL_K3S_MIRROR=cn K3S_URL="https://$MASTER_IP:6443" K3S_TOKEN="$TOKEN" sh -
```

## 正式使用前的一些准备

### 非 root 用户执行 k3s 命令

master 节点非 root 用户执行 kubctl

```bash
# 非 root 用户执行 kubctl 
sudo chmod 644 /etc/rancher/k3s/k3s.yaml
mkdir -p ~/.kube
sudo cp /etc/rancher/k3s/k3s.yaml ~/.kube/config
sudo chown $(id -u):$(id -g) ~/.kube/config

# .bashrc 添加
export KUBECONFIG=~/.kube/config
```

非 root 用户执行 crictl

```bash
sudo tee /etc/crictl.yaml > /dev/null <<EOF
runtime-endpoint: unix:///run/k3s/containerd/containerd.sock
image-endpoint: unix:///run/k3s/containerd/containerd.sock
timeout: 10
EOF

sudo usermod -aG root $USER

newgrp root

crictl images
```


### 非 root 用户执行

### master 节点添加污点

> 该步骤目的: 避免 `master` 节点运行应用 `pod`

```bash
# 查看 master 节点是否存在组织调度污点
kubectl describe node k3s-master | grep Taints

# 不存在, 则手动添加
kubectl taint nodes k3s-master node-role.kubernetes.io/master:NoSchedule
```


### 设置 containerd 国内镜像

#### master 节点

**删除不需要的文件**

```bash
rm -rf /etc/containerd/config.toml
```

**编辑 k3s containerd 配置文件**

> /etc/rancher/k3s/registries.yaml

```toml
mirrors:
  docker.io:
    endpoint:
      - "https://docker.xuanyuan.me"
      - "https://docker.1ms.run"
```

**重启 k3s**

```bash
sudo systemctl restart k3s
```

#### worker 节点

复制 `master` 节点的 `/etc/rancher/k3s/registries.yaml` 文件, 并执行如下命令重启 `agent`

```bash
sudo systemctl restart k3s-agent
```

# 运行一个 nginx 服务

## 配置文件

**nginx-deployment.yaml**

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  selector:
    matchLabels:
      app: nginx
  replicas: 3
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
        - name: nginx
          image: nginx:1.25
          ports:
            - containerPort: 80
```

**nginx-service**

```yaml
apiVersion: v1
kind: Service
metadata:
  labels:
    app: nginx-service
  name: nginx-service
spec:
  ports:
  - port: 80
    protocol: TCP
    targetPort: 80
    nodePort: 30080
  selector:
    app: nginx
  type: NodePort
status:
  loadBalancer: {}
```

## 启动服务

```bash
kubectl apply -f nginx-deployment.yaml
kubectl apply -f nginx-service.yaml
```
