``` bash

multipass launch --name devstudio -c 4 -m 16G -d 50G 24.04
# 工作节点
multipass launch --name work1 -c 2 -m 8G -d 10G 24.04
multipass launch --name work2 -c 2 -m 8G -d 10G 24.04
```

# 主节点 安装 k3s

```bash
curl -sfL https://get.k3s.io | sh -

# 建议使用该命令
curl -sfL https://rancher-mirror.rancher.cn/k3s/k3s-install.sh | INSTALL_K3S_MIRROR=cn sh -
```

# 正式使用前的一些准备工作

## 非 root 用户执行 k3s 命令

最简单的方案就是修改配置文件权限

```bash
# 非 root 用户执行 kubctl 
sudo chmod 644 /etc/rancher/k3s/k3s.yaml
# 非 root 用户执行 crictl
# 重启需要再次执行
sudo chmod 666 /run/k3s/containerd/containerd.sock
```

## master 节点添加污点

> 该步骤目的: 避免 `master` 节点运行应用 `pod`

```bash
# 查看 master 节点是否存在组织调度污点
kubectl describe node devstudio | grep Taints

# 不存在, 则手动添加
kubectl taint nodes devstudio node-role.kubernetes.io/master:NoSchedule
```


## 设置 containerd 国内镜像

### master 节点

**删除不需要的文件**

```bash
rm -rf /etc/containerd/config.toml
```

**编辑 k3s containerd 配置文件**

> /etc/rancher/k3s/registries.yaml

```toml
mirrors:
  docker.io:
    endpoint:
      - "https://docker.xuanyuan.me"
      - "https://docker.1ms.run"
```

**重启 k3s**

```bash
sudo systemctl restart k3s
```

### worker 节点

复制 `master` 节点的 `/etc/rancher/k3s/registries.yaml` 文件, 并执行如下命令重启 `agent`

```bash
sudo systemctl restart k3s-agent
```

# 运行一个 nginx 服务

## 配置文件

**nginx-deployment.yaml**

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  selector:
    matchLabels:
      app: nginx
  replicas: 3
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
        - name: nginx
          image: nginx:1.25
          ports:
            - containerPort: 80
```

**nginx-service**

```yaml
apiVersion: v1
kind: Service
metadata:
  labels:
    app: nginx-service
  name: nginx-service
spec:
  ports:
  - port: 80
    protocol: TCP
    targetPort: 80
    nodePort: 30080
  selector:
    app: nginx
  type: NodePort
status:
  loadBalancer: {}
```

## 启动服务

```bash
kubectl apply -f nginx-deployment.yaml
kubectl apply -f nginx-service.yaml
```
