# 常用插件

## remote ssh

**生成密钥对**

需要使用 powershell 生成的密钥对, 命令如下

```
ssh-keygen -t ed25519
```

某些老旧系统可用如下命令

```
ssh-keygen -t rsa -b 4096
```

**复制公钥**
将生成的公钥复制到目标服务器上

**编辑配置文件**

文件路径: `C:\Users\用户名\.ssh\config`

内容如下

```
Host vagrant-devstudio
	HostName 192.168.56.10
	User vagrant
	IdentityFile C:/Users/laolang/.ssh/id_vagrant_devstudio
	IdentitiesOnly yes
```
