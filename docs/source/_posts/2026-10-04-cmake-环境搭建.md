# 安装 cmake

## 下载

可根据自己的操作系统下载对应的版本 : https://cmake.org/download/

## 环境变量

> 以 ubuntu 24.04 为例

解压后将 `bin` 目录添加到 `path` 即可

```bash
# cmake
export PATH=~/program/cmake-4.4.3/bin:$PATH
```

## cmake-gui

图标文件位置

```bash
$ pwd
/home/laolang/program/cmake-4.4.3/share/icons/hicolor/32x32/apps

$ l
总计 4.0K
-rw-r--r-- 1 laolang laolang 1.6K 2026/08/25 23:17:55 CMakeSetup.png
```

`desktop` 文件示例

```
[Desktop Entry]
Type=Application
Name=CMake GUI
GenericName=Cross-Platform Make
Comment=CMake graphical user interface for configuring and generating build systems
Exec=/home/laolang/program/cmake-4.4.3/bin/cmake-gui %f
Icon=/home/laolang/program/cmake-4.4.3/share/icons/hicolor/32x32/apps/CMakeSetup.png
Terminal=false
Categories=Development;Building;IDE;Qt;
MimeType=text/x-cmake;
StartupNotify=true
Keywords=cmake;gui;build;configure;
```
