  # https://vagrantcloud.com/search.

  # 禁用自动 box 更新检查。如果禁用此功能，
  # 则仅当用户运行 `vagrant box outdated` 时才会检查 box 更新。

  # config.vm.box_check_update = false

  # 访问 "localhost:8080" 将访问虚拟机上的 80 端口。
  # 注意：这会启用对所打开端口的公共访问
  # config.vm.network "forwarded_port", guest: 80, host: 8080

  # 创建一个端口转发映射，允许从宿主机上的端口
  # 访问虚拟机内的特定端口，并仅允许通过 127.0.0.1 访问

  # config.vm.provider "virtualbox" do |vb|

新建一个空白目录, 并执行 `vagrant init` , 此时会生成一个默认的 `Vagrantfile` , 修改内容如下

```ruby
Vagrant.configure("2") do |config|
  # 镜像名称
  config.vm.box = "ubuntu-jammy-22.04"

  # 自动设置时区为 Asia/Shanghai
  config.vm.provision :shell, inline: "sudo timedatectl set-timezone Asia/Shanghai", run: "always"

  # 私有网络
  config.vm.network "private_network", ip: "192.168.56.10"

  # 共享文件夹
  config.vm.synced_folder "data", "/vagrant_data"

  # 磁盘
  config.vm.disk :disk, size: "50GB", primary: true 

  # 虚拟机规格
  config.vm.provider "virtualbox" do |vb|
    # 图形界面
    # vb.gui = true
    # 虚拟机名称
    vb.name = "vagrant-devstudio"
    # 内存
    vb.memory = 16384
    # cpu
    vb.cpus = 4
  end
end
```

# 常用命令

```bash
# 创建虚拟机
# 也可以回复关闭或暂停的虚拟机
vagrant up

# 查看状态
vagrant status

# 关闭
vagrant halt

# 暂停
vagrant suspend

# 回复
vagrant resume

# 重启虚拟机, 也会重新加载 `Vagrantfile` 配置信息
vagrant reload

# 删除虚拟机
vagrant destroy

# 进入虚拟机
vagrant ssh

# 保存快照
vagrant snapshot save k3d-base

# 列出快照
vagrant snapshot list

# 恢复快照（恢复后默认会启动虚拟机）
vagrant snapshot restore k3d-base

# 恢复但不自动启动
vagrant snapshot restore --no-start k3d-base

# 恢复后强制跑 provision
vagrant snapshot restore --provision k3d-base

# 删除快照
vagrant snapshot delete k3d-base
```

# ssh 密钥远程登录

使用 `vagrant ssh-config` 命令可生成默认的配置,然后复制到 `~/.ssh/config` 即可. 兼容 vscode remote ssh 插件的使用

```
 vagrant ssh-config
Host default
  HostName 127.0.0.1
  User vagrant
  Port 2222
  UserKnownHostsFile /dev/null
  StrictHostKeyChecking no
  PasswordAuthentication no
  IdentityFile E:/work/vagrant/vagrant-jx/.vagrant/machines/default/virtualbox/private_key
  IdentitiesOnly yes
  LogLevel FATAL
  PubkeyAcceptedKeyTypes +ssh-rsa
  HostKeyAlgorithms +ssh-rsa
```
