# 配置 VAGRANT_HOME

镜像文件爱你默认保存在C盘, 可以设置环境变量 `VAGRANT_HOME` 来指定位置

# 设置 virtualbox 

`virtualbox` 默认也保存在C盘,可以通过设置修改

# 添加镜像

```bash
# 添加镜像
vagrant box add jammy-server-cloudimg-amd64-vagrant.box --name ubuntu-jammy-22.04
# 查看镜像
E:\work\vagrant>vagrant box list
ubuntu-jammy-22.04 (virtualbox, 0, (amd64))

E:\work\vagrant>
```

# Vagrantfile

新建一个空白目录, 并执行 `vagrant init` , 此时会生成一个默认的 `Vagrantfile` , 修改内容如下

```ruby
Vagrant.configure("2") do |config|
  # 镜像名称
  config.vm.box = "ubuntu-jammy-22.04"

  # 私有网络
  config.vm.network "private_network", ip: "192.168.56.10"

  # 共享文件夹
  config.vm.synced_folder "data", "/vagrant_data"

  # 磁盘
  config.vm.disk :disk, size: "50GB", primary: true 

  # 虚拟机规格
  config.vm.provider "virtualbox" do |vb|
    # 图形界面
    # vb.gui = true
    # 虚拟机名称
    vb.name = "vagrant-devstudio"
    # 内存
    vb.memory = 16384
    # cpu
    vb.cpus = 4
  end
end
```

# 常用命令

```bash
# 创建虚拟机
# 也可以回复关闭或暂停的虚拟机
vagrant up

# 查看状态
vagrant status

# 关闭
vagrant halt

# 暂停
vagrant suspend

# 回复
vagrant resume

# 重启虚拟机, 也会重新加载 `Vagrantfile` 配置信息
vagrant reload

# 删除虚拟机
vagrant destroy

# 进入虚拟机
vagrant ssh
```
