# tsx 语法

## 参考

JSX 简介: https://zh-hans.legacy.reactjs.org/docs/introducing-jsx.html

深入 JSX: https://zh-hans.legacy.reactjs.org/docs/jsx-in-depth.html

## 注意

1. 标签必须闭合：像 `<br>`、`<img>`、`<input>` 等标签，在 `TSX` 中必须写成自闭合形式 `<br />`、`<img />`、`<input />`。
2. 禁止在 `{}` 中写语句：花括号内只能写表达式，不能写 `if`、`for`、`switch` 等控制流语句。
3. 区分 `HTML` 与自定义组件：原生 `HTML` 标签（如 `div`）必须全小写；自定义组件（如 `<MyButton />`）首字母必须大写。

## 示例

```tsx
function App() {

    const name = "React"
    const count = 10
    const imgUrl = "/logo.png"
    const isActive = true
    const handleClick1 = () => {
        console.log("Button clicked!");
    }
    const handleClick = (msg: string = "hello") => {
        console.log("Button clicked!", msg);
    }
    const isLoggedIn = true;
    const fruits = ["Apple", "Banana", "Orange"];
    const htmlContent = "<strong>这是一段加粗的文本</strong>";

    return (
        <>
            <div>
                {/* 变量渲染 */}
                <p>Hello, {name}!</p>
                {/* 数学运算 */}
                <p>Count plus 1 is: {count + 1}</p>
                {/* 函数调用 */}
                <p>Uppercase: {name.toUpperCase()}</p>
            </div>

            {/* 属性绑定 */}
            <div>
                {/* 字符串属性直接写，动态变量用 {} */}
                <img src={imgUrl} alt="Logo"/>

                {/* 类名绑定 (支持模板字符串) */}
                <div className={`box ${isActive ? 'active' : ''}`}></div>

                {/* 样式绑定 (必须传入 JS 对象，属性名使用小驼峰) */}
                <div style={{color: 'red', fontSize: '16px'}}></div>
            </div>


            {/* 事件处理 */}
            <div>
                // 不传参：直接绑定函数引用
                <button onClick={handleClick1}>Click Me</button>

                // 需要传参：必须使用箭头函数包裹，否则函数会在渲染时立即执行
                <button onClick={() => handleClick("参数A")}>Click with Param</button>
            </div>

            {/* 条件渲染 */}
            <div>
                {/* 方式一：三元运算符（适合 if-else 场景） */}
                {isLoggedIn ? <p>欢迎回来！</p> : <p>请先登录</p>}

                {/* 方式二：逻辑与（适合仅当条件为 true 时渲染） */}
                {isLoggedIn && <p>这是只有登录后才显示的内容</p>}
            </div>

            {/* 列表渲染 */}
            <ul>
                {fruits.map((fruit, index) => (
                    // key 通常使用数据的唯一 ID，没有 ID 时勉强使用 index
                    <li key={index}>{fruit}</li>
                ))}
            </ul>

            {/* 渲染原生 HTML 字符串 */}
            // ⚠️ 注意：该属性值必须是一个包含 __html 的对象
            <div dangerouslySetInnerHTML={{ __html: htmlContent }} />
        </>
    )
}

export default App
```

# hooks

`hooks` 的推责

1. 只能在最顶层调用 `hooks`
> 不要在循环、条件语句（如 if）、嵌套函数或 try/catch/finally 代码块中调用 Hook。相反，你应该始终在 React 函数组件或自定义 Hook 的最顶层、且在任何提前返回（return）语句之前调用它们。
> * 原因：React 依赖于 Hook 的调用顺序来追踪和关联状态与副作用。如果调用顺序在每次渲染时发生变化，React 将无法正确管理组件的状态，从而导致 Bug。

2. 只在 React 函数中调用 Hook

> 不要在常规的 JavaScript 函数中调用 Hook。你只能在以下两种地方调用它们：
> * React 函数组件（Function Components）
> * 自定义 Hook（Custom Hooks，即以 use 开头的函数）
> * 原因：这确保了组件中的所有状态逻辑在其源代码中清晰可见，并且自定义 Hook 在被调用时，也依然遵循函数组件渲染时的调用规则。

#### 数组

在 `React` 中你需要将数组视为只读的，不可以直接修改原数组，例如：不可以调用 `arr.push()` ,  `arr.pop()` 等方法。

下面是常见数组操作的参考表。当你操作 React state 中的数组时，你需要避免使用左列的方法，而首选右列的方法：

|避免使用 (会改变原始数组)|	推荐使用 (会返回一个新数组）|
|:--:|:--:|
|添加元素 push，unshift	| concat，[...arr] 展开语法（例子）|
|删除元素 pop，shift，splice | filter，slice（例子）|
|替换元素 splice，arr[i] = ... 赋值	| map（例子）|
|排序 reverse，sort	| 先将数组复制一份（例子）|


```tsx
import '@/assets/styles/common.scss'

import {useState} from 'react'
import {Button, Flex} from 'antd'

function App() {
    const [arr, setArr] = useState<number[]>([1, 2, 3])

    const arrResetHandler = () => {
        setArr([1, 2, 3])
    }

    const arrAddHandler = () => {
        // 末尾新增
        setArr([...arr, arr.length + 1])

        // 头部新增
        // setArr([arr.length + 1, ...arr])
    }

    const arrDeleteWithFilterHandler = () => {
        // 删除第一个
        setArr(arr.filter((v) => v !== arr[0]))
    }

    const arrDeleteWithSliceHandler = () => {
        // 删除第一个
        setArr(prev => prev.slice(1))
    }

    const arrSortByAscHandler = () => {
        // 正序排序
        setArr([...arr].sort((a, b) => a - b))
    }

    const arrSortByDescHandler = () => {
        // 逆序排序
        setArr([...arr].sort((a, b) => b - a))
    }


    return (
        <>
            <div className={`container`}>
                <Flex vertical gap={'middle'} className={`item`}>
                    <Flex justify='center' gap='small'>
                        {arr.map((v, i) => {
                            return <Button shape='circle' key={i}>{v}</Button>
                        })}
                    </Flex>
                    <Flex justify='center' gap='small'>
                        <Button onClick={arrAddHandler}>添加数据</Button>
                        <Button onClick={arrDeleteWithFilterHandler}>删除数据(filter)</Button>
                        <Button onClick={arrDeleteWithSliceHandler}>删除数据(slice)</Button>
                        <Button onClick={arrSortByAscHandler}>正序排序</Button>
                        <Button onClick={arrSortByDescHandler}>逆序排序</Button>
                    </Flex>
                    <Flex justify='center' gap='small'>
                        <Button onClick={arrResetHandler}>重置数据</Button>
                    </Flex>
                </Flex>
            </div>
        </>
    )
}

export default App
```

### useReducer

#### 用法

```tsx
const [state, dispatch] = useReducer(reducer, initialArg, init?)
```

![](/images/2026-08-01-react-基本使用/002.png)

#### 参数

1. `reducer` 是一个处理函数，用于更新状态, `reducer` 里面包含了两个参数，第一个参数是 `state`，第二个参数是 `action`。`reducer` 会返回一个新的 `state`。

2. `initialArg` 是 `state` 的初始值。

3. `init` 是一个可选的函数，用于初始化 `state`，如果编写了 `init` 函数，则默认值使用 `init` 函数的返回值，否则使用 `initialArg`。

#### 返回值

`useReducer` 返回一个由两个值组成的数组：

* 当前的 `state`。初次渲染时，它是 `init(initialArg)` 或 `initialArg` （如果没有 `init` 函数）。 
* `dispatch` 函数。用于更新 `state` 并触发组件的重新渲染。

#### 计数器案例

```tsx
import '@/assets/styles/common.scss'
import { Button, Flex } from 'antd'
import { useReducer } from 'react'
import { MinusOutlined, PlusOutlined } from '@ant-design/icons'

interface numAction {
    type: 'increment' | 'decrement'
}

function App() {
    const numReducer = (state: number, action: numAction) => {
        switch (action.type) {
            case 'increment':
                return state + 1
            case 'decrement':
                return state - 1
            default:
                throw new Error(`Unrecognized action type ${action.type}`)
        }
    }
    const [num, numDispatch] = useReducer(numReducer, 0)

    return (
        <>
            <div className={`container`}>
                <Flex vertical gap={'middle'} className={`item`}>
                    <Flex justify='center' gap='small'>
                        <Button type='primary' shape='circle'>
                            {num}
                        </Button>
                    </Flex>
                    <Flex justify='center' gap='small'>
                        <Button onClick={() => numDispatch({ type: 'increment' })} icon={<PlusOutlined />} />
                        <Button onClick={() => numDispatch({ type: 'decrement' })} icon={<MinusOutlined />} />
                    </Flex>
                </Flex>
            </div>
        </>
    )
}

export default App
```

```tsx
import '@/assets/styles/common.scss'
import { Button, message, Popconfirm, Space, Table, type TableProps } from 'antd'
import { MinusOutlined, PlusOutlined } from '@ant-design/icons'
import { useReducer } from 'react'

interface Product {
    id: number
    name: string
    price: number
    count: number
    isEdit: boolean
}

interface ProductAction {
    type: 'increment' | 'decrement' | 'delete'
    payload: number
}

function App() {
    const productListInitData: Product[] = [
        {
            id: 1,
            name: '手机',
            price: 100,
            count: 1,
            isEdit: false,
        },
        {
            id: 2,
            name: '电脑',
            price: 200,
            count: 2,
            isEdit: false,
        },
        {
            id: 3,
            name: '洗衣机',
            price: 300,
            count: 3,
            isEdit: false,
        },
    ]

    const productListReducer = (state: Product[], action: ProductAction): Product[] => {
        switch (action.type) {
            case 'increment':
                return state.map(item => {
                    return item.id === action.payload ? { ...item, count: item.count + 1 } : item
                })
            case 'decrement':
                return state.map(item => {
                    return item.id === action.payload && item.count > 0 ? { ...item, count: item.count - 1 } : item
                })
            case 'delete':
                return state.filter(item => item.id !== action.payload)
            default:
                throw new Error(`Unrecognized action type ${action.type}`)
        }
    }

    const [productListData, productListDispatch] = useReducer(productListReducer, productListInitData)

    const productColumns: TableProps<Product>['columns'] = [
        {
            title: 'ID',
            dataIndex: 'id',
            key: 'id',
            render: (_, record: Product) => <span>{record.id}</span>,
        },
        {
            title: '名称',
            dataIndex: 'name',
            key: 'name',
            render: (_, record: Product) => <span>{record.name}</span>,
        },
        {
            title: '数量',
            dataIndex: 'count',
            key: 'count',
            render: (_, record: Product) => (
                <Space size={'small'}>
                    <Button
                        shape={'circle'}
                        size={'small'}
                        type={'primary'}
                        icon={<PlusOutlined />}
                        onClick={() => productListDispatch({ type: 'increment', payload: record.id })}
                    />
                    <span>{record.count}</span>
                    <Button
                        shape={'circle'}
                        danger
                        size={'small'}
                        type={'primary'}
                        icon={<MinusOutlined />}
                        onClick={() => productListDispatch({ type: 'decrement', payload: record.id })}
                        disabled={record.count === 0}
                    />
                </Space>
            ),
        },
        {
            title: '价格',
            dataIndex: 'price',
            key: 'price',
            render: (_, record: Product) => <span>{record.price}</span>,
        },
        {
            title: '操作',
            key: 'id',
            render: (_, record: Product) => (
                <Space size='medium'>
                    <a href='javascript:void(0);'>修改</a>
                    <Popconfirm
                        title={`确定要删除商品:${record.name} 吗？`}
                        onConfirm={() => {
                            productListDispatch({ type: 'delete', payload: record.id })
                            message.success('删除成功')
                        }}
                        okText={'确定'}
                        cancelText={'取消'}
                    >
                        <a style={{ color: 'red' }}>删除</a>
                    </Popconfirm>
                </Space>
            ),
        },
    ]

    const productPriceTotal = productListData.reduce((prev, current) => {
        return prev + current.price * current.count
    }, 0)

    return (
        <>
            <Table<Product>
                rowKey='id'
                columns={productColumns}
                dataSource={productListData}
                summary={() => (
                    <Table.Summary fixed>
                        <Table.Summary.Row>
                            <Table.Summary.Cell index={0} colSpan={4}>
                                <strong>总价:</strong>
                            </Table.Summary.Cell>
                            <Table.Summary.Cell index={4}>
                                <strong style={{ color: 'red' }}>￥{productPriceTotal}</strong>
                            </Table.Summary.Cell>
                        </Table.Summary.Row>
                    </Table.Summary>
                )}
            />
        </>
    )
}

export default App
```

#### 处理数组


> 所有的原生数组方法都可以直接使用

```tsx
import '@/assets/styles/common.scss'
import { Button, Flex } from 'antd'
import { useImmer } from 'use-immer'

function App() {
    const [arr, setArr] = useImmer<number[]>([1, 2, 3])

    const arrResetHandler = () => {
        setArr([1, 2, 3])
    }

    const arrAddHandler = () => {
        // 末尾新增
        setArr(draft => {
            draft.push(arr.length + 1)
        })
    }

    const arrDeleteHandler = () => {
        setArr(draft => {
            draft.shift()
        })
    }

    const arrSortByAscHandler = () => {
        // 正序排序
        setArr(draft => {
            draft.sort((a, b) => a - b)
        })
    }

    const arrSortByDescHandler = () => {
        // 逆序排序
        setArr(draft => {
            draft.sort((a, b) => b - a)
        })
    }

    return (
        <>
            <div className={`container`}>
                <Flex vertical gap={'middle'} className={`item`}>
                    <Flex justify='center' gap='small'>
                        {arr.map((v, i) => {
                            return (
                                <Button shape='circle' key={i}>
                                    {v}
                                </Button>
                            )
                        })}
                    </Flex>
                    <Flex justify='center' gap='small'>
                        <Button onClick={arrAddHandler}>添加数据</Button>
                        <Button onClick={arrDeleteHandler}>删除数据(filter)</Button>
                        <Button onClick={arrSortByAscHandler}>正序排序</Button>
                        <Button onClick={arrSortByDescHandler}>逆序排序</Button>
                    </Flex>
                    <Flex justify='center' gap='small'>
                        <Button onClick={arrResetHandler}>重置数据</Button>
                    </Flex>
                </Flex>
            </div>
        </>
    )
}

export default App
```


### useSyncExternalStore

useSyncExternalStore 是 React 18 引入的一个 Hook，用于从外部存储（例如状态管理库、浏览器 API 等）获取状态并在组件中同步显示。这对于需要跟踪外部状态的应用非常有用。

场景

1. 订阅外部 store 例如(redux,Zustand德语)
2. 订阅浏览器API 例如(online,storage,location)等
3. 抽离逻辑，编写自定义hooks
4. 服务端渲染支持
