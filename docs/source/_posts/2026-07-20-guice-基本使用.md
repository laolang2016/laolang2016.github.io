## 简单使用

**SysDictService**

```java
package com.laolang.devstudio.service;

public interface SysDictService {

    String sayHello();
}
```

**SysDictServiceImpl**

```java
package com.laolang.devstudio.service.impl;

import com.laolang.devstudio.service.SysDictService;
import lombok.extern.slf4j.Slf4j;

@Slf4j
public class SysDictServiceImpl implements SysDictService {
    @Override
    public String sayHello() {
        return "hello world";
    }
}
```

**BaseModule**

```java
package com.laolang.devstudio.guice;

import com.google.inject.AbstractModule;
import com.laolang.devstudio.service.SysDictService;
import com.laolang.devstudio.service.impl.SysDictServiceImpl;

public class BaseModule extends AbstractModule {

    @Override
    protected void configure() {
        bind(SysDictService.class).to(SysDictServiceImpl.class);
    }
}
```

**CommonTest**

```java
package com.laolang.devstudio;

import com.google.inject.Guice;
import com.google.inject.Injector;
import com.laolang.devstudio.guice.BaseModule;
import com.laolang.devstudio.service.SysDictService;
import lombok.extern.slf4j.Slf4j;
import org.assertj.core.api.Assertions;
import org.junit.jupiter.api.BeforeAll;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.TestInstance;

@Slf4j
@TestInstance(TestInstance.Lifecycle.PER_CLASS)
public class CommonTest {

    Injector injector;

    @BeforeAll
    public void beforeAll(){
        injector = Guice.createInjector(new BaseModule());
    }

    @Test
    public void testGetInstance(){
        SysDictService sysDictService = injector.getInstance(SysDictService.class);
        log.info("msg:{}",sysDictService.sayHello());
    }

    @Test
    public void testSingletone(){
        SysDictService sysDictService1 = injector.getInstance(SysDictService.class);
        SysDictService sysDictService2 = injector.getInstance(SysDictService.class);
        Assertions.assertThat(sysDictService1 == sysDictService2).isFalse();
        log.info("sysDictService1:{}",sysDictService1);
        log.info("sysDictService2:{}",sysDictService2);
    }
}
```

## 获取单例

默认每次获取新实例, 可通过如下方式获取单例

```java
// 懒汉式
bind(SysDictService.class).to(SysDictServiceImpl.class).in(Singleton.class);
```

如果想要在容器启动时立即创建, 可使用如下方式

```java
// 饿汉式
bind(SysDictService.class).to(SysDictServiceImpl.class).asEagerSingleton();
```

如果只有类没有接口, 也可以用注解 `@Singleton` , 但该注解只能配置为懒汉式

```java
import javax.inject.Singleton;
import lombok.extern.slf4j.Slf4j;

@Slf4j
@Singleton
public class SysDictBusiness {

    public SysDictBusiness() {
        log.info("SysDictBusiness init");
    }

    public String sayHello() {
        return "hello world";
    }
}
```
