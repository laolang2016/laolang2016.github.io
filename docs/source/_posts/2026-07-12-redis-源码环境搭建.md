# 修改配置文件

`redis` 源码目录已经包含了默认的 `redis.conf`, 需要修改几处内容

```init
# 注释该行
# bind 127.0.0.1 -::1

# 修改为 yes
protected-mode no

# 设置最大内存限制
# 内存不够的也可以写 512mb
maxmemory 2gb
```

# 命令行连接

`redis-cli` 编译后也在 `src` 目录, 直接执行 `./redis-cli` 即可连接本地 `redis`

```bash
vagrant@ubuntu-jammy:~/work/opensource/redis-6.2.22/src$ ./redis-cli 
127.0.0.1:6379> config get maxmemory
1) "maxmemory"
2) "2147483648"
127.0.0.1:6379> quit
vagrant@ubuntu-jammy:~/work/opensource/redis-6.2.22/src$ 
```
